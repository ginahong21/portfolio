# Lazy Kingdom 懶惰王國：美夢保衛戰

一款結合手勢魔法與像素美學的互動小遊戲，玩家需施展手勢對抗入侵的「聲音怪」，保衛美夢結界，守護懶惰王國的安寧。

---

## 遊戲玩法

- 玩家角色顯示於左側，在遊戲畫面畫出對應符號魔法攻擊敵人。
- 怪物會從畫面右側不斷出現，頭上標示對應的字母符號（Z、O、U）作為魔法提示。
- 玩家需使用滑鼠（電腦）或手指（手機／平板）畫出相符圖形，發動魔法。
- 手勢正確可驅散怪物，若多次錯誤，怪物速度將加快。
- 每場遊戲有 5 次生命值。怪物若碰觸左側的好眠結界，視為攻擊成功，扣除 1 次生命。
- 點選畫面右下角的「Pause」按鈕可暫停／繼續遊戲與音效。
- 遊戲時間超過 2 分鐘則視為成功，會觸發勝利劇情；若未滿即失敗，會觸發失敗劇情並可重新挑戰。

---

## 操作說明

- 使用裝置：桌機（建議搭配滑鼠）、手機或平板（橫式操作）
- 操作方式：開啟 `html` 即可開始遊戲
- 建議瀏覽器：Google Chrome（支援最新 HTML5 / Canvas 技術）

---

## 技術特色

- HTML5 Canvas 畫布繪圖
- 自訂 $1 Unistroke 手勢辨識演算法
- 音樂與影片引導動畫
- 像素風格介面設計與 RWD 響應式支援
- 遊戲狀態管理（intro、playing、paused、gameOver）
- 錯誤手勢反饋、動畫特效與聲音搭配
